# Console design and implementation references

FuyaoManager uses the robot platform's desktop shell: a sidebar with 208px expanded, 52px icon-rail and hidden modes, an operation bar and an independently scrolling workspace. The sidebar presents the brand, current scope, fixed entry points, grouped navigation and footer. The icon rail keeps icons and group titles of up to two lines, and every entry keeps its accessible name. Hovering the rail or focusing one of its controls floats the complete menu over the workspace without moving the page; Escape dismisses it, and it returns once the pointer leaves or focus enters again. The hidden mode restores from the left end of the operation bar, which shows the brand mark while the rail is shown. The mode is saved per browser. Filters, tabs and primary actions sit in the operation bar. The version control on the right opens the running service version and commit. Narrow screens use a navigation drawer and a wrapping operation bar.

Ant Design tokens and CSS variables share the console's theme, with motion durations of 100, 200 and 300 ms (`--motion-fast`, `--motion-mid`, `--motion-slow`). Panel borders and surface colors set the hierarchy. Forms and records can use 8:4 or 6:6 columns in wide containers and follow natural document flow on narrow ones. Standalone lists use `TablePanel` and `DataTable`, with sticky headers and room for long values. Tables that scroll horizontally expose a named, keyboard-focusable region. The workspace and table content areas fade only at an edge that hides content, and drop the fade under forced colors. Status tags carry five semantics (success, warning, danger, info and neutral) with colors independent of the accent; the tint and border mix into the surface behind them. Tags wrap, and stay on one line inside table cells. Loading states announce "Loading" by default. Versions and identifiers use monospace text. Field labels and the consequences of destructive actions stay visible. Display settings offer a personal content background: 90% of the theme background mixed with 10% of the chosen color.

Paths identify primary pages and site scopes. Query parameters identify tabs and shareable filters. New subviews update the address through `PageTabs` and `usePageQuery`. Back, forward, reload and login restore the selected view. The UI keeps draft confirmations, one-time actions and bulk selections in local state. In-app navigation is protected by the react-router blocker; signing out first asks the active draft guards through `lib/editing/leaveGuard` and clears the session only once leaving is confirmed. Article editing and tables retain their existing components and styles. Categories, tags and media use `?tab=`, with redirects for previous links.

Each route slot is wrapped by `PageBoundary`. A page that fails to render reports the error inside the workspace with a retry, while the sidebar, operation bar and session stay mounted; the failure clears when the location changes.

`App.tsx` and `lib/navigation` own page entry points. Feature code lives in `pages/` and the corresponding `features/`. Tables, panels, version controls and operation-bar slots belong in `components/`. Relative imports point only at the same or a lower layer: `lib`, `components`, `features` and `pages` depend upwards in that order, the entry files are unrestricted, and a component that composes pages belongs in `pages/`. `tests/boundaries.test.ts` checks the import direction and that the page registry in `App.tsx` covers every navigation item. The entry point uses `StyleProvider layer` to give shared styles and component tokens explicit cascade precedence. Site permissions, sessions, date preferences and static publishing follow FuyaoManager's own contracts.

## Adaptation boundary

The sync baseline is commit `7ddbaf0e` (2026-11-24) on the robot platform's `dev` branch. The following belongs to device business or platform infrastructure and is not ported: the 5×3 workbench grid and cards, the cockpit, device and driver pages with the sandbox runtime, the `ContentSurface` background slot, the Kubai icon engine, the status capsule popovers, modular packaging and standalone release artifacts. FuyaoManager's own content motion (albums, friend reordering) and the narrow-screen navigation drawer keep their existing implementations.
